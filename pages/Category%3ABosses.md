# 三眼

[三眼](三眼.md) (游戏内名为 Kolmisilmä) 是一个生成于实验室 并作为游戏的最终BOSS的长腿蜘蛛型生物。

  


[![Monster boss ghost.png](https://noita.wiki.gg/zh/images/Monster_boss_ghost.png?a73147)](/zh/wiki/%E8%A2%AB%E9%81%97%E5%BF%98%E8%80%85 "被遗忘者")

# 被遗忘者

[被遗忘者](被遗忘者.md)（游戏内名为Unohdettu，又称幽灵boss）是在遗忘洞穴中发现的一个小BOSS，位于冰封峡谷深处的西部。它的移动方式无法预测，再加上附近生成的敌人，会让战斗变的非常混乱。

  


[![Monster boss robot.png](https://noita.wiki.gg/zh/images/Monster_boss_robot.png?e603f0)](/zh/wiki/%E4%B8%89%E7%9C%BC%E4%B9%8B%E7%9C%BC "三眼之眼")

# 三眼之眼

[三眼之眼](三眼之眼.md) (游戏内名为Kolmisilmän silmä，又称机械boss) 是一只形似蜘蛛的小boss，在发电站的深处可以找到，有着危险的攻击和独特的特征。

  


[![Monster boss wizard.png](https://noita.wiki.gg/zh/images/Monster_boss_wizard.png?939ab6)](/zh/wiki/%E6%B3%95%E5%B8%88%E4%B9%8B%E4%B8%BB "法师之主")

# 法师之主

[法师之主](法师之主.md)（游戏内名为Mestarien mestari）是在巫师巢穴东边的王座室中遇到的一个小BOSS。它的移动方式类似于高阶炼金术师，虽然它的移动速度相当缓慢，但它会使用一系列极为危险的攻击和给予玩家各种Debuff，可迅速将玩家置于死地。

  


[![Monster gate monster a.png](https://noita.wiki.gg/zh/images/Monster_gate_monster_a.png?26daec)](/zh/wiki/%E9%97%A8%E7%A5%9E "门神")

# 门神

在艺之神殿和艺殿右边的魔法神殿之间有一个奇怪的三角形结构，可以反弹投射物。这个建筑物就是[门神](门神核心.md)。它通常不会有什么反应，但是可以被一些道具唤醒。门神表面的雕纹描述了唤醒它所需的几个提示。

  


[![Monster maggot tiny.png](https://noita.wiki.gg/zh/images/Monster_maggot_tiny.png?a3efef)](/zh/wiki/%E5%B0%8F%E5%B0%8F%E8%9B%86 "小小蛆")

# 小小蛆

[小小蛆](小小蛆.md)（游戏内名为Limatoukka）是在掩埋头骨中生成的一个小BOSS，位于发电站下面的沙漠峡谷再下面的极度致密岩石深处。它永远不会生成在平行世界中。

  


[![Monster boss alchemist progress.png](https://noita.wiki.gg/zh/images/Monster_boss_alchemist_progress.png?810d2e)](/zh/wiki/%E9%AB%98%E9%98%B6%E7%82%BC%E9%87%91%E6%9C%AF%E5%B8%88 "高阶炼金术师")

# 高阶炼金术师

[高阶炼金术师](高阶炼金术师.md)（游戏内名为Ylialkemisti，又叫炼金术师、炼金、大法师）是在黑暗洞穴西边的古代实验室遇到的一个 Boss。它守卫着古代实验室。虽然高阶炼金术师移动非常缓慢，但其强大的召唤攻击很难躲避，对于任何决定穿越古代实验室的玩家来说，它都是一个可怕的敌人。

  


[![Monster Boss dragon.png](https://noita.wiki.gg/zh/images/Monster_Boss_dragon.png?20e344)](/zh/wiki/%E9%BE%99 "龙")

# 龙

[龙](龙.md)（游戏内名为Suomuhauki）是一个类似于蠕虫的小BOSS，在地下丛林右边的龙窟内由玩家靠近龙蛋中心后生成。它除了会使用撕咬攻击之外，还会使用投射物进行攻击。如果要召唤的话还需要挖开龙蛋，因为你需要靠近龙蛋的中心后它才会生成。

  


[![Monster Boss limbs.png](https://noita.wiki.gg/zh/images/Monster_Boss_limbs.png?8806c3)](/zh/wiki/%E4%B8%89%E7%9C%BC%E4%B9%8B%E8%B6%B3 "三眼之足")

# 三眼之足

[三眼之足](三眼之足.md)（游戏内名为Kolmisilmän Koipi，又称金字塔boss）是一个在金字塔中产生的小BOSS。它平时躺在一个祭坛上，只有在玩家足够接近它时才会被唤醒。祭坛上的文字翻译为"你的奖赏"（YOUR REWARD）。 它每隔一段时间就会生成较小的骷髅敌人，通常一次召唤两只，会发射毒性淤泥弹。它的外壳免疫绝大部分伤害，需要等它张开外壳后攻击。 死亡时，与龙相似，它会掉落一个追加最大生命值和一根魔杖。打败它还可以解锁各种法术（见#掉落法术），并且掉落其中随机四种。

  


[![Monster boss pit.png](https://noita.wiki.gg/zh/images/Monster_boss_pit.png?1d0b04)](/zh/wiki/%E9%AD%94%E6%9D%96%E5%93%81%E9%89%B4%E5%AE%B6 "魔杖品鉴家")

# 魔杖品鉴家

[魔杖品鉴家](魔杖品鉴家.md)（游戏内名为Sauvojen Tuntija，又称独眼）是一个会飞行的小BOSS，生成于岩浆湖以东的峡谷上方的桥下。当玩家穿过 魔球室 的中间部分，再越过魔球室入口前致密岩石的突起时，魔杖品鉴家 将在桥下生成，通过以某些方式进入，可以避免它生成。

  


[![Monster fish giga.png](https://noita.wiki.gg/zh/images/Monster_fish_giga.png?11e8f8)](/zh/wiki/%E5%88%A9%E7%BB%B4%E5%9D%A6 "利维坦")

# 利维坦

[深渊生物](深渊生物.md)（游戏内名为 Syväolento）是一个小Boss，在湖中找到。它通常被称为利维坦。

# 三眼之心

[三眼之心](三眼之心.md)（游戏内名称为Kolmisilmän_sydän），位于金字塔左侧沙漠下方的血肉地狱。

# 好朋友

[好朋友](好朋友.md) (游戏内名为Toveri)是一位神秘的敌人。
