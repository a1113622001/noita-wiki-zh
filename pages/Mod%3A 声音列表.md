This page lists all known Noita sound events for usage in mods, sorted by bank file. 

## Usage

  * All list headers are the bank file names, so `animals` ➔ `data/audio/Desktop/projectiles.bank`.
  * All content fields are **events** , except those that are marked with an preceding apostrophe (*) are **snapshots**



One table is one `.bank` file. 

Exact GUIDs are necessary when you want to [replace](https://noita.wiki.gg/zh/wiki/Modding%3A%20Audio%3Faction%3Dedit%26redlink%3D1) an existing sound in-place. 

### Examples

In any Lua script file use the full event path:
    
    
    GamePlaySound("data/audio/Desktop/projectiles.bank", "player_projectiles/flamethrower/create", x, y)
    

When attaching directly to an Entity use the event "root", the FMOD/Noita event engine will then play the appropriate sound effects when the actual events trigger in-game. 
    
    
    <AudioComponent
      file="data/audio/Desktop/animals.snd"
      event_root="animals/wizard"
    ></AudioComponent>
