本攻略提供对高阶法术的两个常用概念：`调用`（Call）和`递归`（Recrusion）的讲解，并用它们来大致说明高阶法术作用时为什么会出现一些反直觉的情况。阅读这篇攻略之前，推荐先阅读[专家攻略：抽取](专家攻略：抽取.md)以便你能知道本文使用的一些术语的含义。 

## 复制和调用

我们先来回顾常规的，不含高阶法术的施法：一根法杖施法时，首先进入`预载`，法杖提供一定数量的`抽取`，然后抽取到法术，扣除对应法力并`执行`它们；法术也可以抽取别的法术，所有被执行的法术的效果总和组成`施法块`。 

接下来我们对`执行`进行一个进一步的讲解：在代码中，每个法术除了有它的伤害、法力消耗等常规字段之外，还有一个独特的函数，这个函数名为`行为`（`action()`），它存储了一个法术被执行时要做的绝大多数事情（除了法力消耗）。也就是说，**执行法术就是在运行法术的行为** 。你可以理解为执行就是做耗蓝以外的工作。 

举个最简单的例子，[火花弹](火花弹.md)的行为是： 

  * 提供一个火花弹投射物实体。
  * 令施法延迟 +0.05。
  * 令散射 -1°。
  * 令暴击率 +5%。



有了这些概念，我们现在就为高阶法术的各种奇奇怪怪的复制行为作一个定义了： 

  * **复制的本质是调用** 。
  * **调用的本质是执行** 。



注意：这里所说的复制，指的是**不通过正常抽取执行某个法术的行为** ，而**不是指使法术数量增加的行为** （通常是[魔杖刷新](魔杖刷新.md)在始终施放法杖中导致的行为）。一般来说，我们描述高阶法术的复制行为，更多地使用“调用”这个词，而不是“执行”。 

于是我们就可以对高阶法术进行进一步的理解了。比如我们知道，[伽马](伽马.md)会复制法杖中最后一个法术，那么我们就可以翻译为：伽马“调用”（或者“执行”）法杖最后一个法术；更进一步，伽马运行法杖最后一个法术的“行为”。当然如果你知道它的[技术细节](专家攻略：高阶法术技术细节.md)的话你会知道其实“最后一个法术”其实是牌库或者手牌的最后的法术。 

然而，有些高阶法术的行为在进行调用的同时，把本应该在正常抽取过程中产生的调整补上。比如[一分为多](一分为多.md)系列法术，在它的行为中，会检查并扣除其目标法术的剩余使用次数。复制类法术没有统一的标准——它们各自之间都略有不同，本攻略将只着重介绍它们共性的部分，也就是它们都是通过**调用** 来复制法术的。 

## 递归

会调用其他法术的法术基本上都在代码中被打上了`递归`（Recrusive）标签，是否递归是一个法术的属性。法杖进行施法时如果进行了调用，则会增加当前行为的`递归等级`，并将其传递给被调用的法术。 

递归的规则可以简单地概括为以下几条法则： 

  * 由抽取执行的法术，递归等级为 0。
  * 如果一个法术调用了一个非递归法术，被调用者的递归等级同调用者。
  * 如果一个法术调用了一个递归法术，被调用者的递归等级等于调用者 +1。
  * 如果当前法术的递归等级大于递归极限，则当前法术不会被执行，调用失败。
  * `递归极限`为 2。



检查递归就是获取将要被调用的法术的递归等级，并判断它是否超过限制。我们接下来讨论的所有法术都是用这种逻辑来限制递归。

[陶](陶.md)的行为是： 

  * 记住牌库中最上面的两个法术。
  * 然后依次调用它们。



我们来解析一下，法杖中的两个陶分别记作 T1 和 T2： 

  * 法杖抽 T1，由于它是通过正常方式抽取的，所以递归等级（记作 rec）为 0。
  * Τ1 (rec = 0) 记住牌库中的前两个法术：Τ2 和火花弹。
  * Τ1 (rec = 0) 调用 T2。因为 Τ2 是递归的，它的递归等级为 0+1=1。 
    * Τ2 (rec = 1) 记住牌库中前两个法术：依然是 Τ2 和火花弹。
    * Τ2 (rec = 1) 调用 Τ2 (rec = 2)。 
      * Τ2 (rec = 2) 记住牌库中前两个法术：Τ2 和火花弹。
      * Τ2 (rec = 2) 尝试调用 T2 (rec = 3)，但是失败了，因为超出了递归限制，什么也没有发生。
      * Τ2 (rec = 2) 调用火花弹 (rec = 2)，成功。
    * Τ2 (rec = 1) 调用火花弹 (rec = 1)，成功。
  * Τ2 (rec = 0) 调用火花弹 (rec = 0)，成功。



最后，施法块中有 3 个火花弹，并添加了 3 份陶的施放延迟。 

注意：T1 执行的全过程中，Τ2 和火花弹一直待在牌库里。

[欧米伽](欧米伽.md)的行为是： 

  * 调用弃牌堆中的所有法术。
  * 然后调用手牌中所有的非递归法术。
  * 最后调用牌库中所有的法术。
  * 魔杖刷新不会被调用。



虽然欧米伽的描述中写着会跳过自己，但是如果像上面这样编杖，就和描述不一样了。 

你已经了解了欧米伽的基本原理了，快试试分析一下上面这个例子吧！ 

我们仍然把两个欧米伽记作 Ω1 和 Ω2： 

  * [伽马](伽马.md) (rec = 0) 调用牌库中的最后一个法术 Ω2 (rec = 1)。 
    * Ω2 (rec = 1) 按顺序调用弃牌堆中的所有法术，弃牌堆中没有法术，所以什么也不会发生。
    * Ω2 (rec = 1) 调用手牌中的所有法术，手牌中的法术是递归法术伽马，所以什么也没有发生。
    * Ω2 (rec = 1) 调用牌库中的所有法术，顺序为： 
      * Ω2 (rec = 1) 跳过魔杖刷新。
      * Ω2 (rec = 1) 调用火花弹 (rec = 1)。
      * Ω2 (rec = 1) 调用 Ω1 (rec = 2)。 
        * Ω1 (rec = 2) 跳过伽马和魔杖刷新。
        * Ω1 (rec = 2) 调用火花弹 (rec = 2)。
        * Ω1 (rec = 2) 跳过两个欧米伽，因为它们的rec=3
      * Ω2 (rec = 1) 调用 Ω2 (rec = 2) 
        * 同上，这次的 Ω2 也调用一个火花弹。



所以，我们发现这样会射击三个火花弹的副本，非常高效（doge）。
