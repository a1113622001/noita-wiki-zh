# 爆炸机制

**来源:** https://noita.wiki.gg/zh/wiki/%E7%88%86%E7%82%B8%E6%9C%BA%E5%88%B6
---

**爆炸** 是游戏中一类非常有用的机制，它们往往具有高额的伤害数值、高效的[挖掘](挖掘.md)能力，但使用不当也会极其危险。   
  
## 爆炸属性

爆炸属性（如爆炸伤害、爆炸半径、爆炸是否具有自伤、爆炸的挖掘能力等等）实际上在游戏中是普遍存在的： 

  * 一般情况下会爆炸的投射物理所当然地有爆炸属性，它们的爆炸开关默认是开启的，因此它们才能发生爆炸。而且这类投射物很可能比你想象的要多得多，常见的[火花弹](火花弹.md)和[分裂弹](分裂弹.md)也是会爆炸的法术，但它们本身的爆炸半径很小、爆炸伤害为 0 ，分裂弹的爆炸甚至没有破坏地形的能力，因此常常被玩家忽略。
  * 一般情况下不会发生爆炸的投射物也有爆炸属性，只不过这些投射物的爆炸开关默认是关闭的，其爆炸属性未被启用。开发者给相当多的这类投射物专门设置了爆炸属性，剩下那些没有专门设置爆炸属性的投射物会使用默认值：[![爆炸伤害](https://noita.wiki.gg/zh/images/Damage_Explosion_dmg-large.png?7e98eb)](/zh/wiki/%E4%BC%A4%E5%AE%B3%E7%B1%BB%E5%9E%8B#爆炸伤害 "爆炸伤害")125的伤害、 20 像素的爆炸半径、带有自伤等等。



通过一些方法能够开启那些一般情况下不会发生爆炸的投射物的爆炸开关，也就能利用上它们的爆炸属性。 

## 爆炸半径与爆炸半径修正[[1]](#cite_note-投射物组件-1)

每一个由法术添加的投射物都拥有一个固有的爆炸半径`explosion_radius`，而每个施法块都有一个**爆炸半径修正**`c.explosion_radius`的属性，初始值为 0 ，一些法术如[易爆](易爆的投射物.md)可以为它所在的施法块提供**爆炸半径修正** 。 

  * 这可以类比投射物伤害：每一个由法术添加的投射物都拥有一个固有的投射物伤害，而每个施法块都有一个**投射物伤害修正** 的属性，初始值为 0 ，一些法术如[伤害增强](伤害增强.md)可以为它所在的施法块提供**投射物伤害修正** 。



不同的是，只有当施法块最终的**爆炸半径修正** 大于 0 时，它才会被加算到投射物固有的爆炸半径上，得到最终的**爆炸半径** 。

## 最低爆炸伤害机制[[1]](#cite_note-投射物组件-1)

如果施法块中最终的**爆炸半径修正** 大于 0 ，那么本施法块的**最低爆炸伤害机制** 会被启用。**注意：** 必须要正数的**爆炸半径修正** 才能触发这个机制，否则无论法术固有的爆炸半径有多大，都将无法获得此机制的加成。 

最低爆炸伤害机制被启用时，最终的**爆炸半径** 超过一定值的爆炸将被赋予一个“保底”（即**最低爆炸伤害** ），若爆炸伤害低于本档的“保底”，则将其设为本档的“保底”。 

     爆炸半径（px） | 最低爆炸伤害   
---|---  
32-63 | 325   
64-127 | 375   
128-10015+ | 500   
  
[玻璃大炮](玻璃大炮.md)、[刀尖舔血](刀尖舔血.md)和[狂暴魔药](狂暴魔药.md)对爆炸半径的乘算在此机制之后计算。例如：拥有一层玻璃大炮时施放一个爆炸半径为 32 像素并且启用了**最低爆炸伤害机制** 的法术，那么它的实际爆炸半径为 32 * 5 = 160 像素，但只应用了 32 像素那一档的**最低爆炸伤害** 。 

还有一些法术也会在之后修改爆炸半径，比如[聚爆](聚爆.md)会为投射物追加一个带有脚本的额外实体，这个额外实体在第 2 帧生效，生效时将投射物的爆炸半径修改为 5 像素，不过这同样不会影响**最低爆炸伤害机制** 的生效。 

关于如何利用**最低爆炸伤害机制** 来高效地增伤，参见[易爆](易爆的投射物.md)。 

## 爆炸开关[[1]](#cite_note-投射物组件-1)

投射物有两种爆炸开关：**存在时间结束爆炸**`on_lifetime_out_explode`和**提前失效爆炸**`on_death_explode` 两种开关。 

对于**存在时间结束爆炸** 开关，顾名思义，它开启之后，投射物会在存在时间`lifetime`结束时发生爆炸。它引起的爆炸是附带施法者信息的。 

对于**提前失效爆炸** 开关，它开启之后，投射物会在失效（除了**投射物的存在时间结束** 导致的失效）时发生爆炸，这又可以分为下列两种情况: 

  * 如果投射物因**碰撞地形** 或者**碰撞实体** 而失效[[2]](#cite_note-2)，那么这种爆炸将带有施法者信息。 
    * [弹跳爆发](弹跳爆发.md)等具有低速失效特性的投射物在低速下失效也属于这种情况。
  * 如果投射物因为其他方式而失效，那么这种爆炸将不会带有施法者信息，从而可以造成[技巧击杀](技巧击杀.md)。常见的“其他方式”有： 
    * 实体移除：比如被[引爆器](引爆器.md)引爆、被[闪灭](闪灭.md)的“短路”移除。
    * 达到了**最大存在时间限制** ：比如[物质吞噬者](物质吞噬者.md)、[混沌拉帕](混沌拉帕.md)、[上方向拉帕](上方向拉帕.md)、[下方向拉帕](下方向拉帕.md)、[复制轨迹](复制轨迹.md)、[投射物能量盾](投射物能量盾.md)这些修正会**限制最大存在时间** 。注意[零时](零时.md)不在此列，它只是将投射物的**存在时间** 设为 1 帧。
    * 液滴的失效：[水 (法术)](https://noita.wiki.gg/zh/wiki/%E6%B0%B4%20%5C(%E6%B3%95%E6%9C%AF%5C) "水 \(法术\)")、[血液(法术)](https://noita.wiki.gg/zh/wiki/%E8%A1%80%E6%B6%B2%5C(%E6%B3%95%E6%9C%AF%5C) "血液\(法术\)")、[油 (法术)](https://noita.wiki.gg/zh/wiki/%E6%B2%B9%20%5C(%E6%B3%95%E6%9C%AF%5C) "油 \(法术\)")、[酸液(法术)](https://noita.wiki.gg/zh/wiki/%E9%85%B8%E6%B6%B2%5C(%E6%B3%95%E6%9C%AF%5C) "酸液\(法术\)")释放后会自行失效。
    * 拥有血量的投射物被击杀：比如[炸弹](炸弹.md)、[花粉](花粉.md)被击杀。
    * 附加有物理实体的实体的物理实体被破坏：比如[召唤岩石](召唤岩石.md)、[丙烷罐](丙烷罐.md)、[炸药箱](炸药箱.md)被破坏。



若一个施法块最终的**爆炸半径修正** 大于 0 ，那么这个施法块下的投射物的**提前失效爆炸** 开关将被开启。

## 爆炸自伤

爆炸要对实体造成爆炸伤害，先决条件是爆炸的**致伤开关**`damage_mortals`开启。绝大多数的投射物这个开关都是开启的，只有少数例外： 

  * ▲ [雾](雾.md)类法术，包括酒雾、血雾、毒雾和粘液雾。
  * ▲ [召唤墙壁](召唤墙壁.md) / [召唤平台](召唤平台.md)
  * [远距离施法](远距离施法.md)
  * [全知之眼](全知之眼.md)
  * [召唤触手](召唤触手.md)
  * [强气流](强气流.md)



▲ \- 带有此标记的法术不能被[引爆器](引爆器.md)移除。 

在这之后，如果爆炸拥有**不伤害施法者**`explosion_dont_damage_shooter="1"`的特性，且它能正确识别施法者（即爆炸具有施法者信息），那么它将不会伤害施法者。 

  * 大部分爆炸物如[炸弹](炸弹.md)、[炸药箱](炸药箱.md)、[火球](火球.md)等都不具有这个特性，它们对施法者不安全，但[陨石](陨石.md)是个例外。
  * 大部分常见的会发生“较小的爆炸”的投射物如[能量球](能量球.md)、[花粉](花粉.md)、[火花弹](火花弹.md)等和大部分常见的在一般情况下不会发生爆炸的投射物都具有这个特性，它们对施法者是安全的。
  * 少数的、使用了默认爆炸属性的投射物不具有这个属性，它们的爆炸开关如果开启了，对施法者不安全。 
    * 要注意这几个常见法术：[冰冷凝视](冰冷凝视.md)、[光明穿凿](光明穿凿.md)、[连锁魔弹](连锁魔弹.md)（的主投射物）、[召唤空心蛋](召唤空心蛋.md)、[召唤蛋](召唤蛋.md)，它们的爆炸开关开启之后发生的爆炸有自伤。



## 其他组件导致的爆炸

以上大部分介绍是针对投射物组件`ProjectileComponent`提供的爆炸的，除了投射物组件外，还有其他一些组件会提供爆炸： 

  * 爆炸组件`ExplosionComponent`
    * 只有[不稳晶体](不稳晶体.md)和它的触发版本、大小两种[炸药箱](炸药箱.md)拥有这个组件。
    * 会在失效时爆炸。
    * 它提供的爆炸不带有施法者信息。
    * 由于开发者的疏忽，这个组件的爆炸开关即使被[无害化](无害化.md)或[移除爆炸](移除爆炸.md)禁用也依然会发生爆炸。
  * 受伤爆炸组件`ExplodeOnDamageComponent`
    * 只有大小两种[炸药箱](炸药箱.md)、[丙烷罐](丙烷罐.md)和[炸弹矿车](炸弹矿车.md)拥有这个组件。
    * 会在收到失效信号、受到伤害和物理实体被破坏超过一定程度时有概率爆炸，三种情况的爆炸概率可以不同。
    * 它提供的爆炸不带有施法者信息。
    * 由于开发者的疏忽，这个组件的爆炸开关即使被无害化或移除爆炸禁用也依然会发生爆炸。
  * 闪电组件`LightningComponent`
    * 电系法术如[闪电弹](闪电弹.md)、[球状闪电](球状闪电.md)等拥有这个组件，[电弧](电弧.md)修正为了保证其能正常工作，也会提供一个辅助性的闪电组件。
    * 除了电弧修正提供的以外，带闪电组件的投射物会在失效时发生爆炸。
    * 会在投射物**存在时间** 只剩下 1 帧时提前移除投射物，因此如果通过正的**爆炸半径修正** 开启闪电弹、球状闪电等的**提前失效爆炸** 开关，由投射物组件提供的那一次爆炸不带有施法者信息，可以造成技巧击杀。
    * 它提供的爆炸带有施法者信息，但也会伤害施法者。
  * 弧组件`ArcComponent`
    * 只有产生的是电弧，且电弧被地形阻隔时才会发生爆炸。
    * [电弧](电弧.md)会在同一施法块的多个投射物之间产生电弧。
    * 爆炸的属性使用投射物的第一个闪电组件的爆炸属性，也即是优先使用投射物自己的闪电组件的爆炸属性，如果投射物自己没有闪电组件，使用电弧修正提供的辅助性闪电组件，这个辅助性的闪电组件的爆炸属性为默认值。
    * 它提供的爆炸不带有施法者信息。



爆炸伤害修正、爆炸半径修正和最低爆炸伤害机制都只对投射物组件提供的爆炸有效。 

无害化会在第 2 帧关闭投射物组件的两种爆炸开关，尝试禁用以上除了弧组件以外会引起爆炸的所有组件，并将伤害设为 0 ，这也会间接导致弧组件不能产生电弧。然而，爆炸组件和受伤爆炸组件不受禁用影响而依然可以发生爆炸，只是伤害被无害化设为 0 。 

移除爆炸会在第 2 帧关闭投射物组件的两种爆炸开关，尝试禁用爆炸组件和受伤爆炸组件。然而，爆炸组件和受伤爆炸组件不受禁用影响而依然可以发生爆炸，并且正常造成伤害。 

被[法术变力量](法术变力量.md)吸收的投射物和被[置换术类法术](黑洞置换术.md)置换的投射物只有投射物组件的两种爆炸开关会被关闭，其他组件不受影响。
